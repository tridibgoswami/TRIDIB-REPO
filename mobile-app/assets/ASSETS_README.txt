Place these image files here before building the production APK:

  icon.png              — 1024x1024 px  (app icon)
  splash.png            — 1284x2778 px  (splash/loading screen)
  adaptive-icon.png     — 1024x1024 px  (Android adaptive icon foreground)
  notification-icon.png — 96x96 px      (Android notification icon, white on transparent)

For development with Expo Go, these are not required.
Expo will generate default placeholders automatically.
